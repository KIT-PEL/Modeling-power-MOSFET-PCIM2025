# Information
This is a supplementary file for the submission to the PCIM 2025 entitled "Accurate Power MOSFET Modeling using Off-the-shelf Instruments."
The design resources for the double-pulse and drain-pulsed test circuits used in the manuscript is shared here.
Each directory contains the gerber data, bill of materials (BOM) with descriptions of the parts used in the schematic, and the image of the test circuit.
